# Kunden-Wiedervorlagen

Typische Anwendungen:

- Angebot nachfassen
- Rückruf vereinbaren
- technische Rückfrage klären
- fehlende Unterlagen anfordern
- Zahlungseingang abklären
- nächsten Kundentermin vorbereiten

Die Wiedervorlage speichert Kunde, Aufgabe, Fälligkeit, Priorität, Verantwortlichen
und Abschlussnotiz getrennt von den eigentlichen Belegen.
