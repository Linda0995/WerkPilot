# Ausgangsrechnungen und Forderungen

## Rechnungserstellung

WerkPilot übernimmt Positionen aus dem Angebot. Für Projekte wird das Ursprungsangebot
verwendet.

## Forderungsmanagement

Die Übersicht zeigt:

- offenen Gesamtbetrag
- überfälligen Betrag
- Fälligkeit innerhalb 7, 14 und 30 Tagen
- Mahnstufe und Datum der letzten Mahnung

## Mahnstufen

- Keine
- Zahlungserinnerung
- Erste Mahnung
- Zweite Mahnung
- Letzte Mahnung

## Exportordner

```text
Dokumente/WerkPilot/Exporte/Ausgangsrechnungen
```
