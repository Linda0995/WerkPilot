# Projektabschlussbericht

## Enthaltene Bereiche

- Projektstatus
- offene Aufgaben
- Zeitcontrolling
- Kostencontrolling
- Netto-Verkaufspreis
- Deckungsbeitrag
- Marge
- Abschlussbeurteilung

## Exportordner

```text
Dokumente/WerkPilot/Exporte/Projektabschlüsse
```

CSV eignet sich für Excel und weitere Auswertungen. Markdown ist als lesbarer,
versionierbarer Projektabschlussbericht vorgesehen.
