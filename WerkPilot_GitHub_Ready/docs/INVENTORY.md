# Lagerbestand und Inventur

## Bestandsgrößen

```text
Verfügbarer Bestand = physischer Bestand - reservierte Menge
```

## Bewegungsarten

- Wareneingang
- Materialausgabe
- Bestandskorrektur Plus
- Bestandskorrektur Minus
- Projektreservierung
- Reservierungsfreigabe

## Inventur

Inventurdifferenzen werden als nachvollziehbare Bestandskorrekturen gebucht. Dadurch
bleibt der vorherige Bestand in der Bewegungshistorie erhalten.

## Mindestbestand

Liegt der verfügbare Bestand unter dem Mindestbestand, markiert WerkPilot den Artikel
als nachzubestellen.
