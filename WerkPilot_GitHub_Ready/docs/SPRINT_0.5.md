# Sprint 0.5 – Foundation

## Ziel
Eine übernehmbare, reproduzierbare Grundlage für alle weiteren WerkPilot-Sprints.

## Abnahmekriterien
- Lösung besitzt eine nachvollziehbare Projektstruktur.
- Desktop-Anwendung startet nach erfolgreichem Restore und laufender PostgreSQL-Datenbank.
- Demo-Kunde wird beim ersten Start angelegt.
- Kunden können gesucht und angelegt werden.
- Kundendomäne verhindert leere Kundennummern und Namen.
- Papierkorbstatus kann gesetzt und zurückgenommen werden.
- Unit-Tests prüfen die zentralen Domänenregeln.

## Nicht enthalten
- Login und Rollen
- Angebotsbearbeitung
- Kalkulation
- Projekte
- Dokumentenablage
- Installer

Diese Funktionen folgen in den nächsten Sprints auf derselben Codebasis.
