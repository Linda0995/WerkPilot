# Globale Suche

Die globale Suche befindet sich im Hauptmenü. Sie durchsucht die wichtigsten
WerkPilot-Stammdaten und Vorgänge gleichzeitig.

## Relevanz

- 100 Punkte: exakte Übereinstimmung
- 80 Punkte: Feld beginnt mit dem Suchbegriff
- 50 Punkte: Suchbegriff ist im Feld enthalten

## Bedienung

Suchbegriff eingeben, Treffer auswählen und doppelklicken oder „Treffer öffnen“
betätigen. WerkPilot öffnet anschließend den zugehörigen Fachbereich.
