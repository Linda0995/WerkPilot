# Kalkulationsmodell

## Kostenarten

- Material
- Arbeitszeit
- Fremdleistung
- Gemeinkosten

Jede Position besteht aus Beschreibung, Menge beziehungsweise Stunden und
Einstandspreis beziehungsweise Stundensatz.

## Berechnung

```text
Positionskosten = Menge × Einstandspreis
Gesamtkosten = Summe aller Positionskosten
Zielgewinn = Gesamtkosten × Firmenziel / 100
Empfohlener Nettoverkaufspreis = Gesamtkosten + Zielgewinn
```

Das Firmenziel ist bewusst nicht als „Standardaufschlag“ bezeichnet. Es ist eine
betriebliche Zielgröße und kann pro Angebotskalkulation angepasst werden.

## Abgrenzung

Die Kalkulation ist intern. Angebots-PDF und E-Mail enthalten ausschließlich die
Verkaufspositionen des Angebots.
