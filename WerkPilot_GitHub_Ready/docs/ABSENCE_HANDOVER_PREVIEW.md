# Übergabevorschau bei Abwesenheiten

Die Abwesenheitsansicht zeigt alle noch offenen Arbeitspunkte eines Mitarbeiters.

## Markierung `Im Zeitraum`

Diese Kennzeichnung bedeutet, dass die Fälligkeit innerhalb des eingetragenen
Abwesenheitszeitraums liegt.

## Übergabeoptionen

### Nur fällige übergeben

Überträgt ausschließlich Aufgaben, deren Fälligkeit innerhalb der Abwesenheit liegt.

### Alle offenen übergeben

Überträgt alle aktuell offenen Kunden- und Projektaufgaben des Mitarbeiters.

Beide Varianten verwenden die bereits hinterlegte Vertretung. Ohne Vertretung und
ohne Übergabegrund ist die Funktion gesperrt.
