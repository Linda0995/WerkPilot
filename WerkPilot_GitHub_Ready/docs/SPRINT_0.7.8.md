# Sprint 0.7.8 – CRM-Wiedervorlagen im Arbeitsfluss

## Fertiggestellt

- CRM-Wiedervorlagen im operativen Dashboard
- Anzahl offener und überfälliger CRM-Nachfassaktionen
- Kunde, Betreff, Verantwortlicher und Fälligkeitsdatum im Dashboard
- CRM-Wiedervorlagen im zentralen Benachrichtigungscenter
- Warnung sieben Tage vor Fälligkeit
- kritische Benachrichtigung bei Überfälligkeit
- Gelesen-Status weiterhin benutzerspezifisch
- direkte Referenz auf den betroffenen Kunden
- keine redundante Kopie der CRM-Daten
- zusätzliche Dashboard-Modelltests

## Fachliche Regeln

- Das Dashboard zeigt offene Wiedervorlagen bis 30 Tage im Voraus.
- Das Benachrichtigungscenter warnt ab sieben Tagen vor Fälligkeit.
- Überfällige Wiedervorlagen werden als kritisch eingestuft.
- Erledigte Wiedervorlagen verschwinden automatisch aus Dashboard und Benachrichtigungen.
- Verantwortliche und Kundennamen werden aus den bestehenden CRM- und Kundenmodulen bezogen.
