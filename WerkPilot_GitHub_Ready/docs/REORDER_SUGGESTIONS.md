# Nachbestellvorschläge

WerkPilot verbindet Lagerbestand und offene Bestelllisten zu einem konkreten
Nachbestellvorschlag.

## Datenquellen

- physischer Lagerbestand
- Projektreservierungen
- Mindestbestand
- offene, noch nicht bestellte Materialpositionen
- Materialstamm und Lieferantendaten

## Exportordner

```text
Dokumente/WerkPilot/Exporte/Nachbestellung
```
