# Belegversand per E-Mail

## Ablauf

1. Belegart auswählen.
2. Beleg auswählen.
3. Vorschau laden.
4. Empfänger, Betreff und Nachricht prüfen oder bearbeiten.
5. Versand auslösen.
6. WerkPilot erzeugt den aktuellen PDF-Beleg.
7. Versandstatus wird dauerhaft protokolliert.

## SMTP-Konfiguration

Der Versand verwendet dieselbe SMTP-Konfiguration wie der Angebotsversand.

## Protokollstatus

- Prepared
- Sent
- Failed

Auch ein fehlgeschlagener Versuch bleibt mit Fehlertext nachvollziehbar.
