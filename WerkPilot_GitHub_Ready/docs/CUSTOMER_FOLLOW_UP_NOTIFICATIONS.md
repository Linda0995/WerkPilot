# Benachrichtigungen für Kunden-Wiedervorlagen

WerkPilot verwendet die bereits bestehende Benachrichtigungszentrale.

## Vorteile

- kein paralleles Warnsystem
- ein gemeinsamer Ungelesen-Zähler
- Meldungen können als gelesen markiert werden
- Hauptdashboard und Benachrichtigungsfenster verwenden dieselben Daten
- bestehende Angebots-, Projekt-, CRM- und Bestellhinweise bleiben erhalten

## Kategorie

Neue Meldungen erscheinen unter:

```text
Kunden-Aufgabe
```

Der Hinweis enthält Aufgabe, Priorität, Verantwortlichen und gegebenenfalls die
Anzahl der überfälligen Tage.
