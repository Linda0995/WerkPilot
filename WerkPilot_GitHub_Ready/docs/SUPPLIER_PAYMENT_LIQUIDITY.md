# Zahlungs- und Liquiditätsmanagement

## Liquiditätsvorschau

WerkPilot aggregiert offene freigegebene Eingangsrechnungen in folgende Zeiträume:

- überfällig
- innerhalb von 7 Tagen
- innerhalb von 14 Tagen
- innerhalb von 30 Tagen

## Skonto

```text
Skontobetrag = Rechnungsbetrag × Skontosatz / 100
Zahlbetrag mit Skonto = offener Betrag - Skontobetrag
```

Skonto wird nur ausgewiesen, solange die Skontofrist noch nicht abgelaufen ist.

## Zahlungen

Teil- und Vollzahlungen werden mit Datum, Referenz, Benutzer und Erstellungszeitpunkt
gespeichert. Die Zahlungshistorie bleibt dauerhaft nachvollziehbar.
