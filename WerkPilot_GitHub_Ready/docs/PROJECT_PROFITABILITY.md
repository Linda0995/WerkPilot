# Projektprofitabilität

Die Nachkalkulation zeigt, ob ein Projekt auf Basis der tatsächlich entstandenen Kosten
noch den geplanten wirtschaftlichen Erfolg erzielt.

## Kennzahlen

- Netto-Verkaufspreis
- geplanter Deckungsbeitrag
- aktueller Deckungsbeitrag
- geplante Marge
- aktuelle Marge
- Ergebnisabweichung

## Status

- Projekt profitabel: aktuelle Marge mindestens 10 Prozent
- Niedrige Marge: positive Marge unter 10 Prozent
- Projekt aktuell im Verlust: negativer Deckungsbeitrag
- Kein Verkaufspreis: Projekt besitzt kein auswertbares Ursprungsangebot
