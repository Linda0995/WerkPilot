# Aufgabenübergabe

WerkPilot kann offene Arbeit eines Mitarbeiters gesammelt an eine andere aktive
Person übergeben.

## Sicherheitsregeln

- Quelle und Ziel dürfen nicht identisch sein.
- Ein Übergabegrund ist Pflicht.
- Mindestens ein Aufgabenbereich muss ausgewählt sein.
- Abgeschlossene und stornierte Kunden-Aufgaben werden nicht übertragen.
- Abgeschlossene Projektaufgaben werden nicht übertragen.
- Die Übergabe ändert keine Fälligkeit und keine Priorität.

Die bestehende Aufgaben-ID bleibt erhalten; dadurch bleiben Bezüge, Historie und
Audit-Trail konsistent.
