# Mahnwesen

## Mahnstufen

1. Zahlungserinnerung
2. Erste Mahnung
3. Zweite Mahnung
4. Letzte Mahnung

## Belegarchiv

```text
Dokumente/WerkPilot/Belegarchiv/Mahnungen
```

Zu jedem Mahnschreiben wird ein SHA-256-Manifest gespeichert.

## Rechtlicher Hinweis

Mahngebühren und Verzugszinsen müssen den jeweils anwendbaren gesetzlichen und
vertraglichen Vorgaben entsprechen. WerkPilot berechnet die vom Benutzer eingegebenen
Parameter, ersetzt aber keine rechtliche Prüfung.
