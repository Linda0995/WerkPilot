# Kundenübersicht 360°

Die Kundenübersicht bündelt alle relevanten Informationen zu einem Kunden in einer
einzigen Arbeitsansicht.

## Bereiche

- Angebote
- Projekte
- CRM-Kontakte
- Wiedervorlagen
- Dokumente

## Kennzahlen

- offenes Angebotsvolumen
- aktive Projekte
- offene Wiedervorlagen
- letzter Kontakt

Die Übersicht ist rein aggregierend. Sämtliche Fachdaten bleiben in ihren jeweiligen
Modulen gespeichert.
