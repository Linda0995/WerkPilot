# Projekt-Zeiterfassung

## Start/Stopp

1. Projekt auswählen.
2. Optional eine Projektaufgabe auswählen.
3. Tätigkeit beschreiben.
4. Start betätigen.
5. Nach Abschluss Stopp betätigen.

## Manuelle Erfassung

Zeiten können nachgetragen oder korrigiert werden. Dabei werden Projekt,
Projektaufgabe, Beschreibung, Beginn und Ende gespeichert.

## Auswertung

WerkPilot zeigt je Projekt:

- Gesamtstunden
- abgeschlossene Stunden
- laufende Stunden
- Anzahl der Zeiteinträge

Eine Verrechnung oder Lohnabrechnung ist in Version 0.11.0 bewusst noch nicht enthalten.
