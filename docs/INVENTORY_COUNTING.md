# Geführte Inventur

## Ablauf

1. Inventur anlegen.
2. Optional Lagerort eingrenzen.
3. Zählung starten.
4. Mengen je Position erfassen.
5. Differenzen prüfen.
6. Inventur buchen.
7. CSV-Protokoll archivieren.

## Buchungswirkung

Beim Buchen erzeugt WerkPilot für jede Differenz eine nachvollziehbare
Bestandskorrektur. Positionen ohne Differenz erzeugen keine Lagerbewegung.

## Exportordner

```text
Dokumente/WerkPilot/Exporte/Inventur
```
