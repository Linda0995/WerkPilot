# Abwesenheiten und Vertretungen

Eine Abwesenheit enthält:

- Mitarbeiter
- Abwesenheitsart
- Zeitraum
- Vertretung
- Notiz
- Status

## Konfliktprüfung

WerkPilot zählt:

- offene Kunden-Wiedervorlagen
- offene Projektaufgaben
- Aufgaben, die während der Abwesenheit fällig werden
- ob eine Vertretung hinterlegt ist

Damit kann vor Urlaubsbeginn oder bei kurzfristigem Ausfall gezielt entschieden
werden, welche Aufgaben tatsächlich übergeben werden müssen.
