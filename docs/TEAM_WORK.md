# Team-Arbeit

Die Team-Ansicht zeigt die operative Arbeitslast aller aktiven WerkPilot-Benutzer.

## Kennzahlen

- aktive Benutzer
- offene Aufgaben
- heute fällige Aufgaben
- überfällige Aufgaben
- dringende Aufgaben

## Pro Benutzer

- Rolle
- offene Aufgaben
- heute fällig
- überfällig
- dringend
- Kunden-Wiedervorlagen
- Projektaufgaben

Die kritischsten Benutzer werden automatisch nach Überfälligkeit, Dringlichkeit
und anschließend Arbeitsmenge sortiert.
