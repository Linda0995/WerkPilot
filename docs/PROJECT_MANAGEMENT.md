# Projektmanagement

## Projektentstehung

Ein Projekt wird aus einem angenommenen Angebot erzeugt. WerkPilot übernimmt:

- Kunde
- Angebotsreferenz
- Angebotstitel
- automatische Projektnummer

Zum Start werden zwei Standardaufgaben angelegt:

1. Projektstart vorbereiten
2. Material und Termine prüfen

## Projektstatus

- Geplant
- Aktiv
- Angehalten
- Abgeschlossen
- Storniert

## Fortschritt

```text
Fortschritt = erledigte Aufgaben / alle Aufgaben × 100
```

Ein Projekt ohne Aufgaben zeigt 0 Prozent. Ein abgeschlossenes Projekt ohne Aufgaben
zeigt 100 Prozent.

## Abschlussregel

„Abgeschlossen“ ist nur möglich, wenn keine offene, laufende oder blockierte Aufgabe
mehr vorhanden ist.
