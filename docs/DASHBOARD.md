# Operatives Dashboard

Das Dashboard zeigt den aktuellen Arbeitsvorrat, ohne den Benutzer mit reinen
Finanzkennzahlen zu überladen.

## Bereiche

- Kunden und Favoriten
- offene Angebote samt Netto-Volumen
- aktive Projekte samt offenen Aufgaben
- fällige und überfällige Projektaufgaben
- aktuelle Angebote und Projekte

## Aktualisierung

Die Werte werden beim Programmstart und über die bestehende Such-/Aktualisierungsaktion
neu aus PostgreSQL geladen.
