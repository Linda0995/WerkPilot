# Meine Arbeit

Die Ansicht `Meine Arbeit` führt persönliche Arbeitspunkte aus mehreren Modulen
zusammen.

## Enthalten

- Kunden-Wiedervorlagen
- Projektaufgaben

## Kennzahlen

- offen
- heute fällig
- überfällig
- dringend
- Kunden-Aufgaben
- Projekt-Aufgaben

## Kritisch-Filter

`Nur kritisch` zeigt:

- überfällige Aufgaben
- heute fällige Aufgaben
- Priorität `High`
- Priorität `Urgent`

Dadurch kann der Benutzer den operativen Fokus auf die wichtigsten nächsten
Schritte reduzieren.
