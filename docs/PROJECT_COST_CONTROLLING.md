# Projektkosten-Controlling

## Sollwerte

Die Sollwerte stammen aus der internen Angebotskalkulation:

- Materialkosten
- Arbeitskosten
- Fremdleistungen
- Gemeinkosten

## Istwerte

- Arbeitskosten: erfasste Stunden × Kalkulationsstundensatz
- Material: manuelle Projektkostenbuchung
- Fremdleistung: manuelle Projektkostenbuchung
- Gemeinkosten: manuelle Projektkostenbuchung
