# Projektzeit-Controlling

## Zweck

Das Projektzeit-Controlling erkennt frühzeitig, ob die tatsächlich benötigte Arbeitszeit
von der Angebotskalkulation abweicht.

## Status

- Kein Budget: keine kalkulierten Arbeitsstunden vorhanden
- Im Zeitbudget: weniger als 85 Prozent verbraucht
- Warnung: 85 bis einschließlich 100 Prozent verbraucht
- Überschritten: mehr als 100 Prozent verbraucht

## Kostenbewertung

Die Ist-Kosten sind eine Controlling-Schätzung. WerkPilot verwendet dafür den
durchschnittlichen Kalkulationsstundensatz aus dem Ursprungsangebot. Eine spätere
Mitarbeiterkosten- oder Lohnabrechnung bleibt davon getrennt.
