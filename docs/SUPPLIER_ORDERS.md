# Lieferantenbestellungen

## Ablauf

1. Nachbestellvorschläge berechnen.
2. Lieferant auswählen.
3. Bestellung aus Vorschlägen erzeugen.
4. Bestellung prüfen und als bestellt markieren.
5. Teil- oder Vollwareneingang buchen.
6. Lagerbestand wird automatisch erhöht.
7. CSV-Bestellung archivieren oder versenden.

## Exportordner

```text
Dokumente/WerkPilot/Exporte/Bestellungen
```
