# E-Mail-Vorlagen und Versandwiederholung

## Vorlagen

Vorlagen werden getrennt nach Belegart gespeichert. Pro Belegart kann eine
Standardvorlage festgelegt werden.

## Versandversuche

Das Protokoll enthält:

- Anzahl der Versuche
- letzten Versuch
- nächsten Wiederholungszeitpunkt
- Fehlertext
- endgültigen Versandstatus

Erfolgreich versendete E-Mails können nicht versehentlich erneut ausgelöst werden.
