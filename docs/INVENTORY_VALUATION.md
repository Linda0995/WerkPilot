# Lagerbewertung

## Kennzahlen

- gesamter Lagerwert
- Reservierungswert
- verfügbarer Lagerwert
- Anzahl Artikel mit veraltetem Einkaufspreis

## Inventur

Inventurdifferenzen werden zusätzlich zur Menge auch wertmäßig ausgewiesen. Damit ist
sichtbar, welche wirtschaftliche Bedeutung eine Bestandsabweichung hat.

## Exportordner

```text
Dokumente/WerkPilot/Exporte/Lagerbewertung
```

Die Auswertung ist eine interne Controlling-Bewertung und ersetzt keine steuerliche
Bewertung durch Buchhaltung oder Steuerberatung.
